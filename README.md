# OPML-FreshRSS
Fichier OPML FreshRSS 

Voici le fichier freshrss_abonnements.opml, prêt à être importé. Il contient une soixantaine de flux répartis en 5 catégories :

Informatique : Korben, Numerama, Next, Clubic, Les Numériques, Frandroid, 01net, Journal du Geek, LinuxFr, Ars Technica, The Verge, Hacker News, etc.
Sécurité informatique : CERT-FR (alertes et avis), ZATAZ, Krebs on Security, The Hacker News, BleepingComputer, Schneier, SANS ISC, etc.
Jeux vidéo : Jeuxvideo.com, Gamekult, Gameblog, IGN France, Canard PC, Eurogamer, Rock Paper Shotgun, PC Gamer, etc.
Domotique : Home Assistant, Jeedom, Domotique-info, Maison et Domotique.
Actualités locales : Nice-Matin.

Pour l’importer : dans FreshRSS, allez dans Abonnements → Import / export, choisissez le fichier, puis validez. Les catégories sont créées automatiquement.
